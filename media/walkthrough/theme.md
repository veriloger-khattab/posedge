# Pick a Posedge color theme

| Theme | Background | For |
|---|---|---|
| **Posedge Graphite** | `#1C1C1C` | everyday work (default) |
| **Posedge Midnight** | `#0F0F0F` | dark rooms, OLED screens |
| **Posedge Daylight** | `#FBFAF7` | bright labs, projectors, code reviews on paper |
| **Posedge High Contrast** | `#000000` | accessibility (every token ≥ 7:1) |

Every color carries meaning for SystemVerilog and UVM. A keyword never changes color, every macro shares one
color, and the ID of a `` `uvm_error `` is red, of a `` `uvm_warning `` yellow.
